# Привет! 👋 Я Роман

Фронтенд разработчик. Пишу код и делаю интерфейсы.

По образованию инженер, развиваю свой стартап **[Logiways](https://logiways.ru/)**, сервис для международной логистики. Когда начинал, думал найму команду разработчиков, но быстро понял, что проще научиться самому. Взялся за HTML/CSS, дальше пошло по нарастающей, сейчас основной стек на React.

Сейчас рынок труда в России сложный, поэтому не работаю как штатный разработчик. Вместо этого развиваюсь самостоятельно, пишу pet проекты и автоматизирую рабочие процессы для себя. Нравится решать реальные задачи кодом, а не просто учиться по туториалам.

Основной стек: React, Redux, TypeScript, Tailwind. Экспериментирую с Next.js, пробую разные подходы к стейт менеджменту.

**Уровень: Junior** (но с практическим опытом)
