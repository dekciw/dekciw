# Всем Привет! 👋 Меня зовут Роман

Я — фронтенд-разработчик, увлечённый созданием удобных и понятных интерфейсов. Люблю превращать идеи в работающие продукты и делать сложное простым.

По образованию я инженер. Мой путь в IT начался с попытки запустить собственный стартап — **[Logiways](https://logiways.ru/)**, веб-сервис для международной логистики.

Изначально я искал разработчиков, которые могли бы помочь реализовать проект, но подходящих специалистов найти оказалось непросто. Тогда я решил попробовать сам: начал с вёрстки, а затем всё глубже погрузился во фронтенд-разработку.

Так началось моё новое направление — создание современных, функциональных и красивых веб-приложений.
С тех пор меня вдохновляют развитие, новые технологии и возможность строить продукты, которые действительно работают.

**Grade: Junior**
